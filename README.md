# Talks

Slides from talks by Rogelio Ruzcko Tobias, published at https://ruzcko.com/talks/.

Each talk is a folder of static files, served at `ruzcko.com/talks/<folder>/`. Pushing to `main` deploys through GitHub Actions (Settings → Pages → Source: GitHub Actions). Name folders after the work and the venue, for example `s2rain-ai4sci-2026`, and add each talk to `index.html`.

Talks are built in their own working folders and copied here when finished. Commit finished versions only: every commit of changed images stays in the history.

- `s2rain-ai4sci-2026`: built from `~/Projects/Presentations/2026-AI4Sci/prototype` with `python3 publish.py`.
